API-туннели

Как мы получаем
данные безопасно.

Вы не доверяете нам свои пароли. Вы выпускаете специальный "одноразовый пропуск" (API-ключ), которому заранее задаете строгие права. В любой момент вы можете «порвать» этот пропуск в своем кабинете.

Аварийный отзыв

Заподозрили неладное? Просто удалите ключ в кабинете маркетплейса. NEXUS мгновенно потеряет весь доступ к вашей статистике без возможности восстановления связи с нашей стороны.

01

Запрос API-ключа

Генерация токена (Read-Only) в вашем кабинете.

02

Безопасный туннель

Передача ключа по TLS 1.3 в зашифрованное хранилище.

03

Связь (Read-Only)

NEXUS извлекает отчёты без изменения данных.

Серверы в РФ

Соответствие 152-ФЗ. Никакой трансграничной передачи данных без шифрования.

Шифрование

Протоколы TLS 1.3 при передаче. AES-256 при хранении чувствительных токенов.

Изоляция

Данные каждого клиента строго изолированы в собственной схеме БД.

Резервное дублирование

Ежедневное автоматическое копирование для защиты от любых сбоев.
