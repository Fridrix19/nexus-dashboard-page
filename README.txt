NEXUS · Кабинет — статическая копия для дизайнера
================================================

Что внутри: продакшен-сборка кабинета как статические HTML-файлы.
Backend нет — это снимок UI 2026-04-29.

КАК ОТКРЫТЬ
-----------
Способ 1 (рекомендуемый) — локальный веб-сервер:

   1. Распакуйте архив куда-нибудь, например в Downloads/nexus-static
   2. Откройте Терминал, перейдите в эту папку:
        cd ~/Downloads/nexus-static
   3. Запустите Python-сервер:
        python3 -m http.server 8080
   4. Откройте в браузере:
        http://localhost:8080/dashboard/

Способ 2 — открыть file:// напрямую:
   Двойной клик на dashboard/index.html
   (некоторые шрифты/анимации могут не работать из-за CORS)

ЧТО СМОТРЕТЬ
-----------
• /dashboard/         — главный экран кабинета (sidebar + чат + правая панель)
• /dashboard/?empty=1 — то же, но без mock-данных (пустой state)
• /                   — лендинг
• /features/          — страница про фичи

ПРАВАЯ ПАНЕЛЬ (наш фокус с Cloud Design)
----------------------------------------
Видна на /dashboard/ справа: Inbox-pattern, 3 таба, time-adaptive Night Sky
background с летающими звёздами и nebula. 8 типов карточек, accordion expand.

Дизайн-токены и keyframes — в _next/static/css/ (chunked).

ВАЖНО
-----
Это static export. Все live-features (real data fetch, websockets, auth)
не работают — это обычно для дизайн-референса достаточно.
